# 🎧 Spotify Clone

## Description

A front-end clone of the Spotify music player built using HTML, CSS, and JavaScript.
This project replicates the UI and basic functionality of a music streaming platform, focusing on user interaction and media controls.


## Features

* 🎵 Play and pause music
* ⏭️ Next and previous track controls
* 🎚️ Progress bar for song duration
* 🔊 Volume control (if implemented)
* 📃 Playlist display
* 🎨 Clean and responsive UI


## Technologies Used

* HTML
* CSS
* JavaScript


## Learning Outcome

This project helped me understand:

* Audio handling in JavaScript
* Event handling and controls
* DOM manipulation
* Building real-world UI clones


## How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
